### 健康度红线清单

**巨石文件 Top8**（>1500行，全部是多人改动的汇合点）：
`ModelEditor.vue 3445` · `ai_middleware.py 3154` · `FloorPlan.vue 2855` · `AIConfigPanel.vue 2101` · `MachineDetail.vue 1655` · `MachineVpo3DView.vue 1545` · `AIFloatingBall.vue 1483` · `MotionPreview.vue 1222`

**重复实现 6 组**（改一处漏五处的根源）：
1. `_resolve_tool_ids` ×3（lots/history/ai_tools）
2. 事件 payload 解析 ×4（ai_tools/history/oxe/db_poller 各一套）
3. 时间列类型反射 ×3（machines/history/db_poller，main.py 启动还要跨文件预热）
4. 表达式求值器双实现：`useExprEval.js`（平台版，读 ext 配置）vs `useExprEval.motion.js`（编辑器版）——**一致性最大风险**
5. `require_model_edit` 依赖 ×3（machines/models/uploads 各自定义）
6. `_find_raw_id_anchor` ×2（lots/history）

**边界越权 3 类**：router import router（lots→machines、uploads→models）；router 用 service 私有函数（rvmessages→db_poller._parse_event_payload、oxe/history→ai_tools 常量）；routers/__init__.py 与实际 17 个挂载不同步。

**死资产**：前端孤儿 3 个（EventList.vue、AlarmStats.vue、useIsoProjection.js）；tests/ 约 75 文件中 ~40 个是一次性遗留；useRafLoop 迁移欠账（4 个 3D 组件仍自管 rAF）。

## 三、代码重组规划：要，分 6 批

**判断依据**：不重组，分工边界立不住——MachineDetail/api/index.js/ai_middleware 是人人要改的汇合点（近 40 提交 MachineDetail 被改 7 次），冲突会回到老路。重组目标不是"美化代码"，是**让目录边界 = 分工边界**。

| 批次 | 内容 | 主刀 | 工时 | 验收 |
|---|---|---|---|---|
| **0 清障** | 删 3 个前端孤儿；routers/__init__ 对齐；backend 根一次性脚本（test_api2 等）移 tests/archive；tests/ 约 40 个遗留文件归档到 tests/archive/（保留 pytest/perf/ai/运维工具） | 洪佳琪 | 0.5天 | 全量 build + 聚焦测试绿 |
| **1 公共层收敛** | 新建 `backend/core/events_query.py`：收拢 tool_ids 解析/payload 解析/时间列反射/raw_id 锚点；`require_model_edit` 统一到 auth；修复 rvmessages→db_poller、oxe/history→ai_tools 的私有引用 | 季世庆 | 1天 | pytest 聚焦套件 + 手测历史/机台/事件三页 |
| **2 AI 拆包** | `services/ai_middleware.py`(3154) → `services/ai/` 包：`providers/{local,openai,dify,n8n}.py` + `usage.py` + `conversations.py` + `middleware.py` 门面；ai_tools→`services/ai/tools.py`（张亮） | 朱明钊(providers) + 张亮(tools) | 2天 | tests/test_ai_middleware_regressions + tests/ai 全绿 |
| **3 前端 api 拆分 + MachineDetail 减脂** | `api/index.js`(411行,15处依赖) → `api/{machines,history,ai,floors,models}.js`（request 封装留 `api/core.js`）；MachineDetail 抽 `useMachinePlayback.js`（回放引擎330行）+ `useRunState.js`（calcRunState 360行）→ 壳子剩 <600 行 | 朱明钊 | 2天 | build 绿 + 回放/实时/AI跳转手测 |
| **4 编辑器与楼层拆分** | ModelEditor 按 4 Tab 拆 4 个子组件（钱鸣）；FloorPlan 抽 `useFloorCanvas/useFloorTools` 组合式（朱明钊）；AIConfigPanel 按 Tab 拆（朱明钊） | 钱鸣 + 朱明钊 | 2~3天 | build + 编辑器四 Tab 手测 + 六机台截图基线对比 |
| **5 动画管线一致性** | `useExprEval.motion.js` 并入平台版 `useExprEval.js`（MotionPreview 改用 ext 配置）；motionDerivers 注册改 `import.meta.glob` 自动发现（消灭 index.js 汇合点） | 钱鸣 | 1天 | 六机台 MotionPreview 回归 + LAM2300 真实事件链 |

**节奏**：本周做批次 0+1（不依赖 Oracle 恢复，正好利用等数据库的时间）；下 Sprint 批次 2+3；再下 Sprint 批次 4+5。每批 = 独立 PR + release tag，出问题单独回退。

**守门机制**（已在 CI）：每批合并前跑 `pytest 聚焦套件 + npm build + 六机台 validate`；批次 2/5 涉及 AI 和动画，额外跑 `tests/ai/` 数据真实门禁和浏览器六台对照。
