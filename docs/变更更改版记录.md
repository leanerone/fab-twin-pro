## 版本号约定

- **ver{大版本}.{小版本}**：如 ver1.0、ver1.1、ver1.2
- 大版本：架构性变更或重大里程碑
- 小版本：功能迭代或修复

## 变更类型

| 类型 | 含义 |
|------|------|
| `feat` | 新增功能 |
| `fix` | 缺陷修复 |
| `refactor` | 重构（不改变外部行为） |
| `docs` | 文档变更 |
| `chore` | 构建/依赖/配置 |
| `breaking` | 破坏性变更（不向后兼容） |
