## ver2.5.5（2026-08-25）— 量产 IIS 修复 SVG 预览报"返回内容不是 SVG"

### 根因
量产环境（IIS）web.config 只有 `APIProxy` 和 `WSProxy` 两条 rewrite 规则，**缺少 `/uploads` 反向代理**。浏览器请求 `/uploads/models/xxx.svg` → IIS 找不到文件（SVG 在后端 backend/uploads，不在前端 dist）→ `SpaFallback` 规则匹配 → 重写返回 `index.html`（200 text/html）→ 前端 `loadSvgInline` fetch 拿到 HTML，不含 `<svg` → 报"返回内容不是 SVG"。

dev 环境正常是因为 [vite.config.js:17](../frontend/vite.config.js#L17) 有 `/uploads` proxy 转发到后端 8002。

### 修改文件
| 文件 | 类型 | 说明 |
|------|------|------|
| `deploy/web.config` | 修复 | 新增 `UploadsProxy` rewrite 规则：`^uploads/(.*)` → `http://127.0.0.1:8002/uploads/{R:1}`（stopProcessing=true，位置在 WSProxy 之后 SpaFallback 之前）；`SpaFallback` conditions 增加 `^/uploads/` 排除（双保险） |

### 验证要点
- 量产 IIS 需已安装 ARR（Application Request Routing）模块（APIProxy 已用 rewrite 到 http://127.0.0.1:8002，说明 ARR 已装）
- 部署后浏览器请求 `/uploads/models/xxx.svg` 应返回 `image/svg+xml`（后端 StaticFiles 处理），不再被 SpaFallback 拦截返回 index.html

## ver2.5.4（2026-08-20）— 模型管理体验修复：SVG预览空白/嵌看板 + 机型无法删除
