## 二、环境依赖

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| Git | 任意 | 并配置**自己的**用户名邮箱（禁止共用 Developer 账号） |
| Python | 3.11 | 后端 |
| Node | ≥20（别用 24，见 AI 布局一节的坑） | 前端 + n8n |
| Oracle | 本地 19c 或可远程连接的实例 | **没有它后端起不来**（config.py 强制 Oracle） |
| Docker + WSL2 | 可选 | 只为本地 Dify；WSL2 启用需重启一次 |

## 三、后端 + 前端启动

```bash
cd backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
# Oracle 连接：默认 fabtwin/fabtwin@localhost:1521/orclpdb
# 不同环境改 config.py 或环境变量（ORACLE_USER/ORACLE_PASSWORD/ORACLE_HOST/ORACLE_SERVICE）
venv\Scripts\python main.py          # 首启自动建表(30张)+补列+建索引+基础种子

cd ..\frontend
npm install
npm run dev                           # http://localhost:5173
```

一键脚本（Windows）：`deploy\start-dev.bat`。

## 四、数据重建（数据库不随 git 走，以下全部幂等）

```bash
# 后端首启已自动建表+基础种子，然后按序：
python scripts\sync_cluster_models_to_db.py all        # 三台 cluster 机型配置+机台行
cd backend
venv\Scripts\python seed_oxe_motion.py                 # OXE 视图配置升级 motion2d
venv\Scripts\python seed_vpo_motion.py                 # PODOPENER 同上
cd ..
python tests\repair_model_configs.py --check           # 七机型配置校验（缺了就去掉 --check 执行）
python tests\generate_today_demo.py                    # 当天演示数据（三机台动画流程）
python tests\generate_oxe_alarms.py --date <今天>       # 告警演示数据
python tests\smoke_baseline.py                         # 冒烟 14 项，必须全 PASS
```

注意：`generate_oxe_alarms` 写 DT_ALARM_EVENT（动画告警流）；机台页告警面板读 `alarms` 表——
两表用途不同，冒烟过 14 项即代表数据就绪。

## 五、AI 服务（n8n 已验证，Dify 半程）

### n8n（真实对接已通，测试 7/7）
- 安装：**npm 直装，无需 Docker**。详细步骤+四个已踩坑：`tests/ai/n8n_local/README.md` + `docs/AI对接真实性测试报告_20261101.md`
- 账号：`admin@fabtwin.local / FabTwin#2026!N8n`
- ⚠️ **Node 版本坑**：用 Node 20（24 会让 sqlite3 编译失败）
- 验证：`bash tests/ai/n8n_local/ai_real_test.sh`（要求 7/7）

### Dify（本机部署到一半：4/6 镜像就位）
- 六服务最小栈的 compose、初始化脚本、离线安装器全部收编在 `tests/ai/dify_local/`（含 README）
- 剩余工作：dify-web / dify-api 两个大镜像因国内镜像源限流未拉到（级联重试脚本在目录里，等窗口或走代理）
- 账号：`admin@fabtwin.local / FabTwin#2026!Dify`（首次由 dify_init.py 自动注册）
- ⚠️ 镜像源坑：Node 20 把 localhost 解析成 IPv6（工作流内访问后端必须写 127.0.0.1）；HTTP 节点对数组响应拆多 item（Code 节点要聚合）

### 后端 AI 配置（存数据库，换机器要重配）

```bash
PUT /api/ai/config  {"n8n_enabled":true,"n8n_base_url":"http://localhost:5678",
                     "dify_enabled":true,"dify_base_url":"http://localhost:8088/v1","dify_api_key":"app-xxx"}
```
