## 附：交接时的三个高频坑

1. **改了 `MACHINE_MODEL_CONFIGS`/机型资产，页面没变化** → `models_config_ttl` 300s 缓存；重启后端或走 API 写路径（会自动失效）。
2. **后端重启后全员要重新登录？** 不会——token 密钥持久化在 `backend/.dev_token_secret`（gitignored）；只有删了它或换机器才会掉线。
3. **`services/` 根下的 `ai_*.py`/`mcp_*.py` 不是重复实现**，是批次2 拆包兼容 shim，tests 还在引用，**勿删勿改**（归属③）。
