### 1.4 基态修复（实测发现）

首轮验证发现动态部件未事件驱动就常亮（没放晶舟也摆着晶舟、没开机腔体灯全亮）。
照 OXE 的做法在生成器里给 **19 个部件**打 `data-motion-base-visibility="hidden"`
（晶舟/三片晶圆/12 腔灯/塔灯红灯），复位引擎会自动隐藏；另把
ALARM_REPORT / STATE 的塔灯动作从对隐藏部件无效的 `opacity` 改为 `visibility`。

### 1.5 安全：两个 P0 均已修

- **P0-1 提权**：`routers/ai.py` 的 `/api/ai/chat`、`/api/ai/chat/stream`：`user_role`
  改为服务端 `current_user.role`，请求体字段不再生效（此前任意登录用户改 body
  即可冒充 admin 触发 n8n / 导出 / 工单）。
- **P0-2 只读端点零鉴权**：`alarms / events / history / lots / oht / oxe / recipes`
  7 个 router 统一加 `dependencies=[Depends(get_current_user)]`（与 10-29 ai.py
  加固同模式）。实测：无 token 全 403、带 token 200，前端页面/事件面板烟雾测试正常。
  注意：前端统一带 Bearer（`api/index.js`），但**外部直连/旧集成若未带 token
  会从 200 变 403**——部署时需知会。

### 1.6 编辑器与存量资产保护

- `ModelEditor` / `MotionPreview`：新增内存草稿校验结果、保存前复检与 errors 阻断；部件清单和 SVG 支持双向高亮。校验后端与 CLI 共用 `validate_content()`，不会形成两套规则。
- `uploads.py`：没有上传历史时，从 `views_config_json.view_2d.svg_source/model_source` 回退读取 SVG；Sym3 真实 UI 成功提取 116 个部件，校验为 0 errors、2 warnings。
- OXE `gen_oxe_svg.py`：旧 `main()` 仅保留为 `_legacy_generate()`；默认拒绝覆盖用户定稿，`--force` 只同步 `<defs>`，写盘前检查非 defs 字节、三段机械臂、`data-pid` 和 SVG×Motion 契约。连续两次强制再生成幂等，最终 SHA256 为 `678d5d4e840c209dfd674af2d3fa00cee1c1295ad149f67addcc7b72ee5c91d4`。
- `sync_legacy_defs.py` 仅对 AMAT、PODOPENER 做字节级 defs 同步；六台源 SVG 与运行时副本哈希一致，未覆盖手绘几何。

### 1.7 AI 中间件修复

- custom/OpenAI/local 路径下，管理员显式 n8n 意图优先进入 n8n 分支，非 admin 不被该分支抢占；`/chat`、`/chat/stream` 继续使用服务端角色，请求体不能提权。
- Dify SSE 改为异步 HTTP 流，避免在异步接口中执行慢速同步请求；流关闭、异常传播和 inputs retry 有聚焦回归。
- AI usage 对 VARCHAR2 日期使用 `SUBSTR` 和字符串日期边界；真实登录 + Oracle 请求 `/api/ai/usage/stats?days=7` 返回 200，不再出现 `TRUNC` 类型错误。
