## 四、风险与依赖

### 4.1 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| Oracle 连接稳定性 | 中 | 后端服务中断 | 连接池 + 重试机制 + SQLite 兜底 |
| DB 轮询性能 | 低 | 大量数据查询影响响应 | 增量查询 + 索引优化 |
| 历史数据量增长 | 中 | 历史回放变慢 | 数据分区 + 归档策略 |
| EAP 真实数据接入不确定 | 中 | 生产环境受限 | 模拟器 + WinForm 双兜底 |
| 前端动画与事件联动不顺畅 | 低 | 演示效果打折扣 | 调试面板（M3）可手动验证 |
| WebSocket 偶发重连 | 中 | 实时推送短暂中断 | 指数退避重连 + 后端 WS 服务排查 |
| 3D 模型为代码生成 | 中 | 模型不够精细 | 箱体拼装器优先 + Blender 备选 |
| WinForm 用 tkinter | 低 | 不够专业 | ver2 可用 C# 重写 |
| 配置化程度不足 | 中 | 新机台仍需改代码 | ModelEditor 升级后解决 |
| LLM 性能问题 | 低 | AI 响应慢 | 缓存常见问题 + 本地规则引擎兜底 |
| 内网依赖安装失败 | 中 | 部署受阻 | 离线包 + WARNING 兜底不阻断 |
