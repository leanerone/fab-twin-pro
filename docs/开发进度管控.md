## 五、OXE 机台接入平台专题（ver2.1.2 → ver2.2）

> 详见 `docs/OXE接入指南.md`（周末开发接续入口文档）

### 5.0 背景与决策

**背景**：OXE 已上量产，目前用独立 HTML 文件部署显示。需要接入平台，支持实时播放与历史回放，后续还要 AI 分析。

**已确认决策**：
- 平台不接收 RV，事件由外部量产系统直接写入 Oracle（`DT_EVENT_RAW`）
- "实时画面" = DB 最新状态轮询（1 秒间隔）
- iframe 作为阶段1 过渡可接受
- 独立 HTML 文件保留备份（不删除）
- AI 分析参考 PODOPENER 实现
- 之前做转换的 OXE 模型（SVG/GLB）保留，与 Canvas 2D 互为补充（Tab 切换）

**废弃决策**：
- ❌ RV 网桥（`tests/oxe/bridge.py` + `router.py` + 7501 端口）不再部署，仅留作参考
- ❌ 外部发布网站不再部署，只作为 Canvas 参考
