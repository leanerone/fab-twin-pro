### 3.2 重建 runbook（数据可全部脚本重建，约 15 分钟）

前置：Oracle 服务能启动（Oracle 程序文件仍在 N:，重插后即可）。

```sql
-- 管理员 cmd: sqlplus / as sysdba（MSYS_NO_PATHCONV=1 注意）
startup
alter session set container=ORCLPDB;

-- 1) 找到并删除损坏的表空间（文件读不出时先 offline drop 再删）
select file_name from dba_data_files where tablespace_name='FABTWIN_DATA';
-- 若直接 drop 报 I/O 错误：
--   shutdown immediate; startup mount;
--   alter database datafile '<上面查到的路径>' offline drop;
--   alter database open;  再回来 alter session set container=ORCLPDB;
drop tablespace FABTWIN_DATA including contents and datafiles;

-- 2) 在 J: 盘（剩余 108GB、同为 NVMe）重建表空间
create tablespace FABTWIN_DATA
  datafile 'J:\ORADATA\FABTWIN\FABTWIN_DATA01.DBF'
  size 2G autoextend on next 512M maxsize 30G;
alter user fabtwin default tablespace FABTWIN_DATA
  quota unlimited on FABTWIN_DATA;
```

## 五、已知问题清单

| # | 问题 | 影响 | 建议 |
|---|---|---|---|
| 1 | CLOB LIKE 全表扫 | F5/F7/F8 检索随数据量线性恶化 | 物化列+索引（优先级最高） |
