# amat_metsput.json 改动说明（v1.0 → v1.1）

> 用 `amat_metsput.json`（你们的原版）和 `amat_metsput_v1.1.json`（改好的版本）做 diff 对比即可看到全部差异。
> SVG 文件不需要改。

---

## 总共改了 5 个地方

| # | 改了什么 | 为什么改 |
|---|---------|---------|
| 1 | `schema_version`: `"1.0"` → `"1.1"` | 版本号 |
| 2 | `coord.type`: `"logical"` → `"svg_user_space"`，加 `viewBox` | 平台需要 viewBox 做坐标转换 |
| 3 | 新增 `parts` 数组 | 平台需要知道有哪些部件、中文名、3D 对应关系 |
| 4 | 每个 rotate 加 `"axis": "z"` | 2D 固定绕 Z 轴转，3D 时可指定 x/y/z |
| 5 | 每个 action 加 `"duration"` 和 `"easing"` | 平台需要知道动画时长和缓动方式，否则会瞬移 |

---

## 逐条说明

### 1. schema_version

```diff
- "schema_version": "1.0"
+ "schema_version": "1.1"
```

### 2. coord 加 viewBox

```diff
  "coord": {
-   "type": "logical",
+   "type": "svg_user_space",
    "unit": "px",
    "origin": "bottom_left",
-   "y_axis": "up"
+   "y_axis": "up",
+   "viewBox": [0, 0, 720, 900]
  }
```

> viewBox 值 `[0, 0, 720, 900]` 来自 SVG 的 `width="720" height="900"`。

### 3. 新增 parts 数组

原版没有 parts，v1.1 新增：

```json
"parts": [
  {
    "part_id": "ARM_2",          ← 必须和 SVG 里的 id 一致
    "part_name": "Wafer Handler Robot",  ← 中文名，平台 UI 显示用
    "part_type": "group",       ← SVG 元素类型
    "anchors": [{"name":"pivot","x":0,"y":900}],  ← 旋转中心
    "view_3d": "ARM_2_3D",      ← 3D 对象标识，没3D可省略
    "desc": "顶部晶圆传送机械臂"
  },
  ...
]
```

> 只需要列出**会动的部件**。CH_1~CH_4、ARM_1、SMIF_1 等不动的不用加，但加了也不报错。

### 4. rotate 加 axis

```diff
- { "type": "rotate", "angle": 45, "pivot": {"x":0,"y":900} }
+ { "type": "rotate", "angle": 45, "axis": "z", "pivot": {"x":0,"y":900}, "duration": 800, "easing": "mechanical" }
```

### 5. 所有 action 加 duration + easing

| 动作 | duration（毫秒） | easing | 说明 |
|------|-----------------|--------|------|
| ARM_2 rotate | 800 | `mechanical` | 机械臂旋转，有惯性感 |
| ARM_2 offset（0位移） | 0 | - | 位移为0，瞬时 |
| Group1/2_CST offset | 600 | `mechanical` | 载具升降，有惯性感 |

> duration 填 0 = 瞬时完成（无动画过渡）
> easing 可选值：`linear`(匀速) / `mechanical`(机械感) / `ease-in`(加速) / `ease-out`(减速) / `ease-in-out`(两端缓)

---

## SVG 不需要改

`amat_metsput.svg` 完全不需要改动。只要保证：
- 会动的元素有 `id`（你们的已经有了：ARM_2、Group1_CST 等）
- 顶层 `<svg>` 有 `width` 和 `height`（已经有了：720×900）

---

## 后续其他机台怎么交付

照这个模式产出两份文件即可：

```
models/user/
├── {model_id}.svg      ← 带部件 id 的矢量图
├── {model_id}.json     ← 按 v1.1 格式写的动作配置
```

平台通过 `POST /api/uploads/models` 一次性上传两份文件，自动解析入库。
