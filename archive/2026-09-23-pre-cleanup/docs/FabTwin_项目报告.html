FabTwin Pro

半导体工厂数字孪生平台

项目进度报告  |  2026年7月24日

一、项目概述

项目定位：构建半导体晶圆工厂数字孪生平台，实现机台实时监控、历史数据回放、楼层平面图可视化及AI辅助分析。

当前版本：ver1.4（已完成核心功能开发）

项目团队：后端/前端开发 + 3D模型/数据对接

技术栈 说明
后端Python 3.10+ / FastAPI / SQLAlchemy 2.0 / Oracle 19c
前端Vue 3.4 + Vite 5 + Three.js（3D）+ Canvas/SVG（2D）
通信REST API + WebSocket 实时推送
AI多Provider支持（智谱GLM / DeepSeek / OpenAI等）
数据库Oracle 19c（生产）/ SQLite（开发调试），19张业务表 + 3张AI表

三、核心功能

3.1 机台实时监控与可视化

主页看板 7个KPI卡片（运行/空闲/告警/产量/WIP/节拍/OEE）+ 楼层切换 + 机台列表
多视图渲染 支持5种视图模式：Three.js 3D / 等角2.5D / SVG 2D / VPO 2D / VPO 3D
机型覆盖 PODOPENER开盖机 / TEL DRM UNITY刻蚀机 / OXE刻蚀机，共33台机台
实时推送 WebSocket实时广播，端到端延迟 ≤ 1秒，指数退避自动重连

3.2 历史数据回放

回放功能 日期选择 + 6档倍速控制（0.5x~16x）+ 24h柱状时间轴 + 事件拖拽跳转
事件数据 PODOPENER 7天10920条历史事件，含20种事件类型 + 5类告警
查询性能 单日历史查询响应 ≤ 2秒

3.3 楼层平面图与3D场景

3D楼层视图 机台3D模型 + 状态灯 + 区域标注 + 天车轨迹动画 + 点击跳转详情
2D平面图编辑 5种编辑工具 + 拖拽调整 + JSON导入导出 + 天车2D动画
楼层支持 4层楼层（1F-4F），37个区域，含设备区/过道/STK/PUMP等

3.4 AI辅助查询（新完成）

多Provider支持 智谱GLM / DeepSeek / 通义千问 / OpenAI，一键切换，配置持久化到Oracle
Token使用统计 按Provider分布 + 每日统计 + 可视化图表，成本可控
模型实时切换 悬浮窗口下拉菜单，响应显示当前Provider和Model
本地规则引擎 Lot查询 + 机台状态 + 告警统计 + 温度趋势 + 产量统计 + 异常检测（7类）
Function Calling 支持AI工具调用，不支持的Provider自动降级重试

3.5 事件-动画配置系统

统一配置层 JSON配置文件驱动动画，新机型接入无需改代码（podopener.json + schema）
调试面板 5个子Tab：时间轴/事件列表/手动触发/配置热编辑/动画录制
事件映射 PODOPENER PACKING 14阶段 + UNPACKING 12阶段全部映射

五、数据驱动模式

模式 数据流 用途
模拟器模式 内部模拟器 → DB → 轮询 → WS → 前端 Demo演示
DB轮询模式 WinForm/EAP写入 → DB → 轮询 → WS → 前端 测试联调
TIBRV模式 TIBRV → Redis/MQTT → 后端 → WS → 前端 生产目标

注：模拟器与DB轮询模式可同时启用、互不干扰；TIBRV模式为ver2.0目标。
